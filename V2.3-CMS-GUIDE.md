# Helen Wells portfolio | CMS future-proofing V2.3

This update makes additions in Pages CMS more predictable without redesigning the site. **V2.3 includes the SEO V2.2 changes.** It is safe to apply whether or not you already installed that SEO patch.

## Install

1. Extract this ZIP into the existing Astro project **root**, preserving relative paths and merging folders.
2. Commit and push to GitHub, or run `npm run check:content` and `npm run build` locally first.
3. Reload Pages CMS. New editorial fields appear automatically.
4. No need to change the headshot, résumé, or existing links.

## What changes

1. **Skills:** CSS grid automatically wraps any number of groups with consistent separation. Add skills/groups in Pages CMS > Website content > Skills.
2. **Featured artwork:** The hardcoded Grayton Beach text is removed. The large feature now uses optional per-article text fields from Pages CMS > Website content > Writing samples. When blank, it uses "FEATURED STORY" and that article's publication name. The "Read the guide" link becomes "Read the article" so it also works for non-guide pieces. **To preserve the original "GRAYTON BEACH" design text**, open the Royal Destinations sample in Pages CMS and set its "Featured artwork small label" to `FEATURED GUIDE` and its "Featured artwork big text" to `GRAYTON BEACH`. The saved fields will follow *that sample*, not a different spotlight later.
3. **Results intro/attribution:** New Pages CMS > Website content > Section text (writing & SEO results). These fields contain the existing Frias-specific wording initially, so nothing needs copying or retyping. When updating results from other projects, Helen can edit this text right in Pages CMS.
4. **Spotlight selection:** If more than one article is marked Spotlight, the first one wins, and `npm run check:content` issues a warning rather than failing deployment. If none are marked, it uses the first Featured item, otherwise the first sample. For clarity, the editor should ideally check only one. Featured cards are no longer limited to four; the grid wraps automatically.

## Files in the patch

- `.pages.yml` (new fields/editor)
- `src/pages/index.astro` (dynamic artwork, resilient spotlight, CMS-editable results text, V2.2 SEO tags)
- `src/styles/site.css` (adaptive skill grid and long-title safety)
- `src/data/sections.json` (**new** editable file with the existing results text)
- `scripts/check-content.mjs` (nonfatal spotlight warnings; section checks)
- `astro.config.mjs` (V2.2 canonical site URL)
- `src/pages/sitemap.xml.ts`, `src/pages/robots.txt.ts` (V2.2 native SEO routes)

### Important preservation note

This ZIP intentionally **does not contain** `src/data/site.json`, `src/data/samples.json`, `src/data/skills.json`, or `src/data/results.json`. Your deployed headshot and résumé paths, skills and published writing links are untouched. It also doesn't contain any uploaded images or PDF files.

### Deployment check

- Run `npm run check:content`, `npm run build`.
- Confirm writing sample list, featured artwork and skills still display correctly on mobile and desktop.
- Confirm `https://helen-wells.netlify.app/sitemap.xml` and `/robots.txt` load.
- In Pages CMS, add a temporary skill, save it, and verify Netlify deploys it; remove it afterward if desired.

No additional packages, CMS plugins, or JavaScript dependencies required.
